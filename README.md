# 🛍️ Myntra Functional Clone

A fully functional **Myntra Clone Website** built using **HTML, CSS, and JavaScript**, designed to replicate the core shopping experience of the popular fashion e-commerce platform **Myntra**.  

👉 **Live Demo:** [Myntra Clone on Vercel](https://myntra-clone-seven-smoky.vercel.app/)

---

## 🚀 Features

- 🧾 **Product Listing Page** – Displays a wide range of products with images, prices, and brand names.  
- 🔍 **Filtering and Sorting** – Filter products based on categories and sort by price or rating.  
- ❤️ **Wishlist Functionality** – Add or remove items from the wishlist.  
- 🛒 **Add to Cart System** – Add, view, and remove products from the cart.  
- 📱 **Responsive Design** – Works smoothly on all devices (mobile, tablet, and desktop).  
- 💬 **Interactive UI** – Hover effects, animations, and smooth transitions for a real shopping feel.
